# Design system Tidiva

La palette reprend les quatre couleurs du logo : pin (#05331F), fougère (#426443), sauge (#A7BC89) et ivoire (#F5EBD6). Le texte et le fond échangent pin et ivoire en mode sombre. Les cartes utilisent un voile de sauge ; les sélections ajoutent un contour et une coche.

Les anneaux de Today affichent le pourcentage et le nombre de tâches terminées. Sur simulateur, les arguments de lancement `-sampleHome -tidiva.onboardingComplete YES` permettent de vérifier cette page avec trois tâches en mémoire.
